## 🔹 Step 1 — Build SQL Tool

Create a tool that converts NL → SQL → Executes via Databricks SQL.

```python
from databricks import sql

class SQLQueryTool:
    name = "sql_query_tool"

    def __init__(self, warehouse_id):
        self.warehouse_id = warehouse_id

    def run(self, query):
        with sql.connect(
            server_hostname="<workspace-host>",
            http_path=f"/sql/1.0/warehouses/{self.warehouse_id}",
            access_token="<token>"
        ) as conn:
            cursor = conn.cursor()
            cursor.execute(query)
            return cursor.fetchall()
```

---

## 🔹 Step 2 — Build Agent Runtime

```python
class AgentRuntime:

    def __init__(self, spec, model_client):
        self.spec = spec
        self.model_client = model_client
        self.sql_tool = SQLQueryTool(warehouse_id="your_warehouse")

    def run(self, user_input):

        sql_prompt = f"""
Convert the following question into SQL 
for table main.sales.transactions:

{user_input}

Return SQL only.
"""

        sql_query = self.model_client.generate(sql_prompt)

        result = self.sql_tool.run(sql_query)

        return result
```

## 🔹 Step 3 — Wrap as MLflow Model

```python
import mlflow.pyfunc

class AgentModel(mlflow.pyfunc.PythonModel):

    def load_context(self, context):
        self.agent = AgentRuntime(load_spec(), load_model())

    def predict(self, context, model_input):
        return self.agent.run(model_input["query"])
```
