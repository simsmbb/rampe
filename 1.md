# 🧱 PHASE 1 — Define the Agent Contract (Your Internal DSL)

This is the foundation. Everything else depends on it.

## Step 1.1 — Define Agent Spec Schema

Create a strict schema (Pydantic or JSONSchema):

```python
class AgentSpec(BaseModel):
    agent_name: str
    description: str
    model: str
    tools: list[str]
    data_sources: list[dict]
    memory: dict
    guardrails: dict
    deployment: dict
```

This spec becomes:

* The output of your meta-agent
* The input to your deployment engine
* The stored artifact in your metadata store

---

## Step 1.2 — Define Brick Types

Create reusable building blocks:

| Brick          | Responsibility     |
| -------------- | ------------------ |
| RAGBrick       | Vector search      |
| SQLBrick       | NL → SQL execution |
| ForecastBrick  | ML model inference |
| APIBrick       | External API calls |
| GuardrailBrick | Safety validation  |

Each brick must implement:

```python
class Brick:
    def register(self, agent_runtime):
        pass
```

This ensures modular composition.

# 🏗 PHASE 2 — Build the Agent Runtime Template

This is the standard runtime every agent uses.

## Step 2.1 — Create Base Agent Runtime

```python
class BaseAgent:
    def __init__(self, spec):
        self.spec = spec
        self.tools = []
        self.memory = None

    def register_tool(self, tool):
        self.tools.append(tool)

    def run(self, user_input):
        plan = self.plan(user_input)
        result = self.execute(plan)
        return result
```

---

## Step 2.2 — Wrap in MLflow PyFunc

Every agent becomes deployable via MLflow.

```python
class AgentModel(mlflow.pyfunc.PythonModel):
    def load_context(self, context):
        self.agent = load_agent_from_spec()

    def predict(self, context, model_input):
        return self.agent.run(model_input["query"])
```

This makes all agents uniform.
