# EPIC 1 — Canonical Object Registry

# Problem It Solves

Enterprise systems represent the same entity differently.

Example:

```text id="g5d1p8"
Guidewire Claim = claim_id
CRM Ticket = case_number
Data Lake Record = event_id
```

No shared operational identity exists.

Without canonical objects:

* agents reason inconsistently
* workflows break
* relationships fragment
* governance becomes impossible

---

Build a centralized ontology object runtime.

# Database Tables

## ontology_objects

```sql id="ml5f3m"
CREATE TABLE ontology_objects (
    id UUID PRIMARY KEY,
    tenant_id UUID NOT NULL,
    object_type TEXT NOT NULL,
    canonical_id TEXT NOT NULL,
    current_version INT NOT NULL,
    state TEXT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

---

## ontology_object_versions

```sql id="d5q0jv"
CREATE TABLE ontology_object_versions (
    version_id UUID PRIMARY KEY,
    object_id UUID REFERENCES ontology_objects(id),
    version INT,
    payload JSONB,
    created_at TIMESTAMP
);
```
