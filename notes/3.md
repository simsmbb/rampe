# MONTH 1 — Canonical Object Foundation

# Objective

Create the foundational ontology object model.

This is the single most important phase.

---

# Build

## 1. Object Registry Service

Create:

```text
ontology-object-service
```

Responsibilities:

* object CRUD
* object typing
* versioning
* metadata
* tenancy
* state management

---

# Database Schema

Use PostgreSQL.

## Tables

### ontology_objects

```sql
CREATE TABLE ontology_objects (
    id UUID PRIMARY KEY,
    tenant_id UUID,
    object_type TEXT,
    canonical_id TEXT,
    version INT,
    state TEXT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);
```

---

### ontology_object_versions

```sql
CREATE TABLE ontology_object_versions (
    version_id UUID PRIMARY KEY,
    object_id UUID,
    payload JSONB,
    created_at TIMESTAMP
);
```

---

### ontology_object_types

```sql
CREATE TABLE ontology_object_types (
    type_name TEXT PRIMARY KEY,
    schema JSONB,
    lifecycle JSONB
);
```
